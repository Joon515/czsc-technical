# 缠论本体 · 本图结构层

[源码](pine/chanlun.pine)：单一 TradingView Pine v6 指标，无第三方库；只用本图行情，不请求跨周期数据。
在 Pine Editor 中保存并添加这一份脚本。图上仅保留价格结构、原买卖点与确认K线的短提示：

- 不绘制MA线、MACD线/柱、成交量柱或均量线，不再创建成交量轴或辅助数值面板；声明为 `overlay=true, scale=scale.none`，没有任何辅助数值plot。
- MA/MACD/VOL仍在内部计算，辅助信息转入确认K线标记的悬浮说明，不改变K线原始涨跌颜色。
- 原结构买卖点仍标在发生极点，且文字保持单行；辅助符号标在事件收盘确认的K线，不回标成发生时已经知道。

替换旧版本后若旧坐标轴范围仍残留，移除旧指标实例再添加并恢复价格轴自动缩放；已有服务器提醒须重建。若对象树确认截图里的源码块是独立Text图形，应单独隐藏该对象，脚本不会修改手工绘图。

## 显示与结构
默认开启“叠加本图结构层”，层数 **3**：

| 层 | 来源 | 颜色 |
| --- | --- | --- |
| S1 | 确认笔组成的线段 | 蓝 |
| S2 | 确认 S1 段的连接节点继续分段 | 橙 |
| S3 | 确认 S2 段的连接节点继续分段 | 紫 |

各层独立确认，只向上传递冻结段；不足不画、不复制。关闭叠加仅计算、绘制 S1。
默认显示线段、中枢核心、标记；笔／未完成虚线／大状态面板默认关闭，在“显示”开启。笔固定第77课口径。
“显示”只含开关。颜色与字号在“样式”组中作为输入项调整：买向、卖向、冲突提示、S1/S2/S3与笔颜色；K线提示/状态字号（默认小）与结构点字号（默认正常）。Pine 的 Style 页只收 plot 类对象，标签、线、框的样式无法进入该页，因此不再尝试放入 Style 页。线宽按层级固定为 S1/S2/S3 = 1/2/3；中性灰随图表前景色自适应，不作为输入。
S1/S2/S3 是同图结构层，不是 1／5／30 分钟级别，不构成原著全部走势类型递归的证明。分段用首尾相连的冻结节点；中枢取其时间区间内原 K 线的完整高低范围，不将内部极值接成反时序的笔。

## 中枢方框
- 核心固定为首三段实际区间的闭交 **[ZD, ZG]**，允许单价交集；GG/DD 是同向 Z 段包络。
- 横向仅覆盖第一成员起点至最后接纳成员终点，不用确认时刻拉长；属显示约定，不冒称原文坐标。
- 完整离开暂时冻结；回试返回才接纳离开／返回两段并延伸。三类破坏后永久冻结，连接段不进入新中枢。
- 三买回试低点 `≥ ZG`、三卖回试高点 `≤ ZD`，触及边界也可确认破坏（第20课）。

## 标记与提醒
买向绿色小上箭头、卖向红色小下箭头，文字如 `3买·S2`，`S2` 是结构层；候选 `1? / 2?` 半透明显示。
`1? / 2?` 始终是候选，缺少严格背驰力度证据；`3` 是本层区间破坏标记。确认滞后于发生，回标不代表当时可知或可按该价成交。
提醒含确认买卖、收盘进出中枢、分层合取；候选默认关闭。合取须同类别、方向、候选身份，默认至少 2 层、确认间隔 ≤20 根本图 K 线；同源行情非独立周期证据。
提醒选独立条件或 **Any alert() function call**。JSON 含匹配 `levels`、本图 `timeframe`、类别、方向、发生／确认／观察时间与价格，每次收盘最多一条聚合消息。旧提醒是服务器快照，更新源码后须重建。
盘中进出中枢（默认开）是三条独立条件：盘中离开上沿、离开下沿、回到中枢内。比较对象是现价与前一确认收盘、以及最新确认中枢；中枢仍来自确认结构，盘中出现的离开或回归可能在收盘前撤回。Create Alert 时频率选“每根K线一次”，避免同根K重复。盘中条件不进 `alert()` JSON，且不含买卖点：买卖点需要未确认K上的结构回滚，当前未实现，仍只在确认后提醒。
“高级”预算默认原 K 线 18000、每类结构对象 6000；耗尽明确停止、显示原因并保留确认状态。淘汰旧图形不改计算历史。

## MA / MACD / VOL 与本体
结构摄入不依赖辅助指标暖机、量能或显示开关；辅助状态仅接实际摄入的收盘原K，预算拒收那根不推进MA吻周期。不增加独立买卖提醒，也不将候选升级为严格买卖点。

- **MA 吻**：默认 SMA 5/10。用快线顺向斜率减缓、间距收敛识别吻开始，重新顺向分离识别吻结束。实际换边是湿吻；碰线后原侧恢复不算湿吻。未穿越按最小间距/前分离峰值 ≤0.5 近似唇吻，否则飞吻。原文没有这些数值阈值，这是可配置近似，不是吻的充分必要定义。
- **第15课吻间力度**：面积为 `[前吻结束, 后吻开始)` 内每根图 K 的 `abs(短MA-长MA)` 之和（价·图K）；平均力度为面积/根数（价）。上涨、下跌分别保存上一同向已完成周期，比较总面积和平均力度。开始根不入旧周期，结束根入新周期；左侧未知的首周期不作基准。正在形成的平均力度只标“暂态”，不覆盖完成比较；MA 缺值清空周期链与基准。
- **S层 MACD**：默认 12/26/9（Pine `ta.macd` 柱为 DIF−DEA）。只比较本层上一同向冻结段，统计原 K `(at,bt]` 的方向柱面积 `sum(max(dir*hist,0))` 与方向 DIF/DEA 峰值，正负柱不相抵。间隔中两线同时落入各自前段峰值的20%以内记“回零参考”；比例可配置，不能把反向段冒称中枢 B，也没有自动证明第24课 A/B/C 角色。MACD 对一字板等情形的局限仍在。
- **VOL**：段间比较平均每根成交量，不用总量把长段误报为强；同样取 `(at,bt]`，共享端点只归前段。逐根量比只对比前20根均量，排除本根；默认 ≥2倍放量、≤0.5倍缩量。前根放量后本根骤缩提示缠绕风险参考，是对第12课定性描述的近似，不是卖点或骗线结论。
- **未知不当弱势**：缺任意一根量则该窗口/段均量未知；真实零量保留，零基准不产生比率。MACD 各项缺值独立传播；没有前同向段时等待，不跨层比较，也不把延伸中虚线保存为基准。

默认开启“K线辅助”中的“确认K辅助标记”。买向标记在确认K下方，卖向在上方；同一K、同方向的多层事件合并为一个标记，双向分别保留，同一K最多两个。符号只有四种：

| 符号 | 含义 |
| --- | --- |
| ● | 本K该方向事件均获三辅减弱参考 |
| ○ | 存在中性/分歧，但无缺项、无增强反证 |
| ? | 存在缺项，但无已知增强反证 |
| ! | 至少一个事件存在增强反证（琥珀色） |

冲突优先于缺项，中性与支持其次；颜色不代表买卖指令。悬停时逐条列出同向事件的 MA/MACD/量能相对前同向段的状态，并给出本K MACD柱与量比。最多保留最近180个标记，使用独立队列，不挤占原240个结构点标签；关闭标记不影响计算、结构或提醒。

同层证据仍按上一同向冻结段比较：
- MA：段内 `max(dir*(短MA-长MA),0)` 的平均分离减弱/增强，**不是第15课吻间面积**；段终点吻状态来自当时原K快照。
- MACD：柱面积减弱且DIF/DEA方向峰值均未增强才算减弱参考；任一增强标为冲突，缺项不伪支持。
- VOL：均量收缩/扩张。真实0参与比较，0对0为中性；缺值未知。
“三辅支持”是可选保守筛选，不是原文硬三合公式，也不证明严格背驰。“候选仅显示/提醒三辅支持”默认关闭；开启后只筛 `1?/2?` 的显示与提醒，不删结构记录、不影响上层输入、不筛三类事件。

原结构点的悬浮说明含结构原因、发生／确认／观察时间与价格，以及本段的辅助状态和对前同向段的比值（<1 减弱、>1 增强）。确认K标记的悬浮列出同K各事件的辅助状态。吻间周期和S层确认段是不同区间，不能混成同一“趋势力度”。
买卖事件JSON的冻结 `auxiliary` 保留 `scope/current/previous/intervening_zero_reference`，增加 `evidence`（`ma/macd/volume`：0缺项、1减弱、-1增强、2中性；`supported`）。区间增加 `ma_mean_gap/ma_kiss_at_end`，原有时界、方向、根数、MACD面积/峰值、均量保留。未知数值为JSON `null`，中枢进出事件仍 `auxiliary=null`；合取快照属于代表事件的层，不是各层力度合成。

## 验证
先用 `npm ci` 安装依赖，再运行：
```sh
npm test
npm run check:pine
```
PineTS 是独立运行器；编译接口未公开且可能变更，编译不等于图表执行，均不替代 TradingView 实时回滚、Bar Replay、服务器通知实测。
辅助计算/格式化函数保留“局部结果赋值后返回”的普通 Pine 写法，避免 PineTS 0.11.0 连续转译含调用的条件返回式时污染共享 AST；不修改运行器依赖或验证断言。
PineTS将force_overlay绘图存入独立overlay容器，验证读取器同时读取普通与overlay真实快照；原几何断言不变。图表验证使用原装adapter与价格坐标，不使用双轴桥接或伪造曲线。
离线 BTC 夹具保留真实 OHLC 与5分钟间隔，仅平移至固定历史时钟，**不含成交量**；不能据此验证 VOL。合成 OHLCV 或为真实 OHLC 配置的合成量均不冒充交易所价量。
