# 缠论本体 · 本图结构层

[源码](pine/chanlun.pine)：TradingView Pine v6，无第三方库；不恢复 MACD／MA／VOL。
普通时间 K 线图中，将全部源码粘贴到 Pine Editor 并添加指标；只用本图行情，不请求跨周期数据。

## 显示与结构
默认开启“叠加本图结构层”，层数 **3**：

| 层 | 来源 | 颜色 |
| --- | --- | --- |
| S1 | 确认笔组成的线段 | 蓝 |
| S2 | 确认 S1 段的连接节点继续分段 | 橙 |
| S3 | 确认 S2 段的连接节点继续分段 | 紫 |

各层独立确认，只向上传递冻结段；不足不画、不复制。关闭叠加仅计算、绘制 S1。
默认显示线段、中枢核心、标记；笔／未完成虚线／大状态面板默认关闭，在“显示”开启。笔固定第77课口径。
S1/S2/S3 是同图结构层，不是 1／5／30 分钟级别，不构成原著全部走势类型递归的证明。分段用首尾相连的冻结节点；中枢取其时间区间内原 K 线的完整高低范围，不将内部极值接成反时序的笔。

## 中枢方框
- 核心固定为首三段实际区间的闭交 **[ZD, ZG]**，允许单价交集；GG/DD 是同向 Z 段包络。
- 横向仅覆盖第一成员起点至最后接纳成员终点，不用确认时刻拉长；属显示约定，不冒称原文坐标。
- 完整离开暂时冻结；回试返回才接纳离开／返回两段并延伸。三类破坏后永久冻结，连接段不进入新中枢。
- 三买回试低点 `≥ ZG`、三卖回试高点 `≤ ZD`，触及边界也可确认破坏（第20课）。

## 标记与提醒
买向小上箭头、卖向小下箭头；如 `5·S2·3买`，数字是本图周期，S 是结构层。
`1? / 2?` 始终是候选，缺少严格背驰力度证据；`3` 是本层区间破坏标记。确认滞后于发生，回标不代表当时可知或可按该价成交。
提醒含确认买卖、收盘进出中枢、分层合取；候选默认关闭。合取须同类别、方向、候选身份，默认至少 2 层、确认间隔 ≤20 根本图 K 线；同源行情非独立周期证据。
提醒选独立条件或 **Any alert() function call**。JSON 含匹配 `levels`、本图 `timeframe`、类别、方向、发生／确认／观察时间与价格，每次收盘最多一条聚合消息。旧提醒是服务器快照，更新源码后须重建。
“高级”预算默认原 K 线 18000、每类结构对象 6000；耗尽明确停止、显示原因并保留确认状态。淘汰旧图形不改计算历史。

## 验证
先用 `npm ci` 安装依赖，再运行：
```sh
npm test
npm run check:pine
```
PineTS 是独立运行器；编译接口未公开且可能变更，编译不等于图表执行，均不替代 TradingView 实时回滚、Bar Replay、服务器通知实测。
离线 BTC 保留真实价量、5 分钟间隔，仅平移至固定历史时钟；与原时钟现场行情及确定合成场景分开，合成不是交易所行情。
